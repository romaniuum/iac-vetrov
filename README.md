# iac-vetrov

Репозиторий по курсу «Инфраструктура как код». Вариант 09, префикс `vetrov-09`, облако — Yandex Cloud.

## Каталоги

- `work-01/` — практика 1: первая машина, `create.sh` и `destroy.sh`, `commands.sh` — просто журнал команд
- `work-02/` — практика 2: две машины за балансировщиком, шаблон cloud-init, `check-lb.sh` ждёт ответов через балансировщик
- `hw-01/` — ДЗ 1: стенд с NAT и сервером приложения, подробнее в `hw-01/README.md`
- `.gitlab-ci.yml` — пайплайн из практики 3

## Стенд второй работы

Нужны `yc`, `jq`, `envsubst` и ключ `~/.ssh/id_ed25519.pub`.

```bash
bash work-02/create.sh
bash work-02/check-lb.sh
bash work-02/destroy.sh
```

Ключ сервисного аккаунта в репозитории не хранится, в пайплайн он передаётся переменной `YC_KEY_LAB` (тип File).
